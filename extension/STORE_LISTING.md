# Chrome Web Store listing copy (Yureka extension)

Paste these into the Developer Dashboard when you resubmit **v1.0.3+**.
Required for the **Affiliate Ads** policy (Grey Titanium).

## Short description (≤132 characters)

```
Coupons & gift-card tips for stores you visit. Some links are affiliate links; we may earn a commission at no extra cost to you.
```

## Detailed description

```
Yureka helps you find coupons, marketplace deals, and gift-card savings while you shop on sites like Amazon, Flipkart, and Myntra.

AFFILIATE DISCLOSURE (important)
Some deal and offer links shown by this extension are affiliate links, including links from CueLinks partner programs. If you click an affiliate link and make a purchase, Yureka may earn a commission. This does not change the price you pay.

How affiliate links work in Yureka
• Affiliate links are only opened after you take an action (for example: accepting the disclosure, then clicking “Open deal”, a coupon card, or “Enable deals”).
• The extension does not silently rewrite page URLs or inject affiliate codes into the address bar without your action.
• You can dismiss on-page tips at any time.

What else Yureka shows
• Coupons and marketplace offers for the store you are browsing
• Optional gift-card checkout tips when a matching card is available
• Links into the Yureka web app for the full catalog

By using the extension and enabling deals, you acknowledge this affiliate disclosure.
```

## Single purpose / privacy notes (if asked)

- Single purpose: surface shopping deals, coupons, and gift-card savings for the current site.
- Affiliate monetization is disclosed in the listing, popup consent screen, popup footer, and on-page bar.
